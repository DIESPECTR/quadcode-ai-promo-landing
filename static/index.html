FROM THE FIRST PROMPT TO THE FINISHING TOUCHES

BLOOM CARE.
A brief you can build on.

A brand brief becomes a complete visual direction: soft pinks, elegant type and a product-led page. Follow the same three steps with your own idea.

EXCERPT FROM THE STARTING PROMPT
“Build a single-page landing site for BLOOM CARE — a premium Japanese skincare brand built around sakura extract.”

The direction: Japanese minimalism, blush pink and cream, serif headlines and generous whitespace.

  1. 01 / SET THE DIRECTION

    A specific brand, not “make it pretty”.

    The first prompt names the product, audience and visual mood. The guide uses Claude Sonnet to build the page.

  2. 02 / GIVE THE PAGE A STORY

    Turn the brief into sections.

    Request a hero, bestseller cards, a serum spotlight, the formulation story and a full collection. The agent creates the layout and copy.

  3. 03 / REFINE THE EXPERIENCE

    Polish, then inspect the result.

    Add restrained scroll animations and hover states. The guide shows the finished page in a recorded scroll-through; it does not demonstrate a working checkout.
