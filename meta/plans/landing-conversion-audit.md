### Черновики ответов оператора (не публиковать до утверждения условий)
Подставлять значения только из утверждённых условий, приватного реестра и проверенного экрана погашения. Не просить пароль, коды входа или платёжные данные. Текст с кодом отправлять **только в приватном ответе канала** после ручного решения и закрепления заранее активированного уникального кода; никогда не вставлять код в публичный лендинг, URL, скриншот или аналитику.

- **Acknowledgement:** “Thanks for messaging the Quadcode AI channel about the promo. We review requests manually. A message does not guarantee a code or a reply within a specific timeframe.” После утверждения времени ответа добавить точный интервал.
- **Approved (only after verification):** “Your request is approved under the published offer terms. Your code: [assigned active code]. Redeem it at [verified screen/path] by [verified expiry and timezone]. [Verified payment/plan restrictions, if any]. If it doesn’t work, reply here privately.” Заполнить все применимые поля и сверить код с реестром до отправки.
- **Not eligible:** “Thanks for your interest. Based on the published offer terms, this request isn’t eligible: [approved reason]. If you think this is an error, reply here privately.” Не раскрывать внутренние антифрод-сигналы.
- **Repeat request:** “We’ve already handled this request in this channel conversation. Please check our earlier private reply; if your assigned code isn’t working, reply here and we’ll investigate.” Если исходное сообщение недоступно, сверить реестр и безопасно повторить **тот же** код, а не назначать новый.
- **No active codes / paused:** “We can’t issue a promo code right now. We can’t promise a code or a reply by a specific time.” Не обещать обратную связь, если команда не сможет её дать.
- **Code problem:** “Please reply here privately with the error you see and where you tried to redeem your code. Don’t post your code publicly; we’ll check the assigned code and the confirmed redemption steps.” Не запрашивать пароль или платёжные данные.
